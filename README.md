# 🎬 CinemadeAnny

Portal de cinema com visual Old Hollywood — resenhas, filmes, séries, documentários e opinião do público.

## Como colocar no ar (GitHub Pages) — pelo celular

### 1. Crie uma conta no GitHub
- Baixe o app **GitHub** ou acesse github.com no navegador
- Crie sua conta (se ainda não tiver)

### 2. Crie um repositório novo
- Nome sugerido: `cinemadeanny`
- Deixe como **Public**
- **Não** marque “Add a README”

### 3. Suba os arquivos
Você precisa enviar estes arquivos/pastas:

```
index.html
css/
  └── style.css
js/
  ├── app.js
  └── data.js
README.md
```

**Pelo app do GitHub:**
1. Abra o repositório
2. Toque no botão **+** → **Upload files** (ou “Create new file” e vá colando)
3. Envie todos os arquivos mantendo as pastas `css` e `js`

### 4. Ative o GitHub Pages
1. No repositório, vá em **Settings** (Configurações)
2. No menu lateral, toque em **Pages**
3. Em “Source”, escolha a branch **main** (ou master) e a pasta **/ (root)**
4. Salve

Em 1–2 minutos o site estará no ar em:
`https://SEU-USUARIO.github.io/cinemadeanny`

## Área Administrativa

- Acesse a aba **Admin** no menu
- Senha padrão: `anny2024`
- Lá você pode criar, editar e excluir resenhas

**Recomendado:** depois de subir o site, altere a senha no arquivo `js/app.js` (procure por `anny2024`).
